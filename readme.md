# Angular - Lista 2

## Sobre o Projeto
Este repositório contém uma aplicação frontend desenvolvida em Angular, construída exclusivamente para fins de estudo e aprimoramento técnico. 

O projeto tem como objetivo a aplicação prática de conceitos avançados e padrões arquiteturais de nível corporativo (Enterprise) no framework. O desenvolvimento foca na resolução de cenários complexos do mundo real, abordando os seguintes tópicos de estudo:

* Roteamento Avançado e Segurança: Implementação de Guards para proteção de rotas e HTTP Interceptors para injeção de tokens e tratamento global de erros.
* Formulários Complexos: Criação de formulários dinâmicos reativos utilizando FormArrays e desenvolvimento de validadores customizados (síncronos e assíncronos).
* Programação Reativa Avançada (RxJS): Orquestração de múltiplos fluxos assíncronos de dados utilizando operadores de combinação e resiliência, como forkJoin, combineLatest e retry.
* Performance e Componentização: Criação de componentes reutilizáveis através de projeção de conteúdo (ng-content) e otimização de carregamento (lazy loading em nível de template) utilizando o bloco de controle de fluxo @defer.

## Tecnologias Utilizadas
- Angular
- RxJS
- TypeScript
- HTML5 / CSS3

## Como Executar

1. Certifique-se de ter o [Node.js](https://nodejs.org/) e o [Angular CLI](https://angular.io/cli) instalados em sua máquina.
2. Clone este repositório:
   ```bash
   git clone https://github.com/Jotajhones/estudos_angular_basico_2.git

```

3. Acesse o diretório do projeto:
```bash
cd estudos_angular_basico_2

```

4. Instale as dependências do projeto:
```bash
npm install

```

5. Inicie o servidor de desenvolvimento:
```bash
ng serve

```

6. Acesse a aplicação no navegador através do endereço `http://localhost:4200/`.
